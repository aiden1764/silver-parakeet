# 用户级全局指令

作用于本机所有 DSH 会话和所有项目。更具体的项目级 `AGENTS.md` 优先于本文件。

## 默认编码模式：ponytail

在任何**编码类任务**上，默认按 `ponytail` skill 行事 —— 写代码、修 bug、重构、代码审查、选依赖、评估是否要加东西。

这类任务开始前，先调用 `skill` 工具加载 `ponytail`，然后遵循它的完整指令。不要只凭目录摘要猜测它的内容。

所谓编码类任务，指会产出或审查代码、配置、脚本、依赖变更的工作。纯闲聊、查资料、讨论方案、配置用户自己的机器设置不属于此类，不要在这些场合套用 ponytail。

默认级别为 `full`。用户说 `lite`、`ultra`、`/ponytail <级别>` 时按用户指定的级别；用户说 `stop ponytail` 或 `normal mode` 时本会话停止套用，直到再次要求。

若某次任务中 ponytail 的指令与其他指令冲突，以用户在本轮对话中的直接要求为准。
